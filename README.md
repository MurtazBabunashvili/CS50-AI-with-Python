# CS50 AI with Python

A collection of projects completed for Harvard University's
“CS50’s Introduction to Artificial Intelligence with Python” course.

This repository contains implementations of classic AI algorithms and problem-solving techniques including:

* Search algorithms
* Knowledge representation
* Logical inference
* Game-playing AI
* Constraint satisfaction
* Optimization

These projects were built using Python as part of learning foundational artificial intelligence concepts through hands-on implementation.

---

# Projects

## 1. Degrees

Implementation of a search-based AI that finds the shortest connection path between actors through movies they have starred in.

### Concepts Used

* Breadth-First Search (BFS)
* Graph traversal
* State-space search
* Shortest path algorithms

### Features

* Finds the minimum number of movie connections between two actors
* Uses real movie and actor datasets
* Demonstrates uninformed search techniques

---

## 2. Tic-Tac-Toe

An unbeatable Tic-Tac-Toe AI built using the Minimax algorithm.

### Concepts Used

* Minimax
* Recursive game trees
* Adversarial search
* Utility functions
* Decision making

### Features

* Plays perfectly against humans
* Evaluates optimal future moves
* Uses recursive search for best outcomes

This project demonstrates how classical game-playing AI works.

---

## 3. Knights

Logic puzzle solver based on Knights and Knaves problems.

### Concepts Used

* Propositional logic
* Knowledge bases
* Logical inference
* Model checking

### Features

* Solves logical truth-teller puzzles
* Represents statements symbolically
* Uses automated reasoning to infer solutions

---

## 4. Minesweeper

An AI agent capable of playing Minesweeper using logical inference.

### Concepts Used

* Knowledge-based agents
* Logical inference
* Constraint propagation
* Propositional logic

### Features

* Infers safe cells and mines
* Maintains a dynamic knowledge base
* Makes intelligent moves using reasoning instead of guessing

The project focuses heavily on reasoning systems and inference engines.

---

## 5. MazeRunner

A maze-solving AI project focused on pathfinding and search algorithms.

### Concepts Used

* Graph search
* Pathfinding
* State exploration
* Search optimization

### Features

* Navigates through maze structures
* Finds efficient paths to the goal
* Demonstrates classic AI search techniques

# Running Projects

Clone the repository:

```bash
git clone https://github.com/your-username/CS50-AI-with-Python.git
```

Move into a project directory:

```bash
cd minesweeper
```

Run the project:

```bash
python runner.py
```
